# 股票买入适配度分析 Skill

## 一、目标

判断一只股票“现在适不适合买”，而不是只判断“公司好不好”。

核心公式：

好生意 + 好公司 + 好价格 + 好时机 + 适合你的仓位 = 可考虑买入

## 二、使用方式

用户输入最好包含：

- 股票名称/代码：
- 市场：A股/港股/美股等
- 持有期限：短线/中线/长线
- 风险偏好：保守/中等/激进
- 当前是否持仓、成本：
- 可提供的数据：最新股价、PE、财报、公告等

若未提供，默认：

- 市场：A股
- 期限：中线
- 风险：中等
- 状态：未持仓
- 数据：基于公开信息或用户提供信息，并标注数据日期和时效

若关键实时数据无法获取或无法核验，不得编造；应明确列入数据缺口，并在数据严重不足时暂不下结论。

## 三、分析流程

### 1. 能力圈与资金属性

- 我是否真的理解它怎么赚钱？
- 投资期限是否匹配？
- 是否用闲钱？能承受多大回撤？
- 机会成本如何？有没有更好标的？

### 2. 生意模式

- 收入来源是什么？
- 成本结构如何？
- 客户粘性、转换成本高不高？
- 是否强周期？现在处于周期什么位置？
- 护城河：品牌、专利、牌照、网络效应、成本优势、规模效应。
- 是否有定价权？

### 3. 行业与竞争格局

- 行业空间、增速、渗透率。
- 竞争格局：CR5、龙头地位、是否内卷。
- 政策与监管：鼓励、中性还是限制。
- 技术变革风险。
- 上下游议价能力。

### 4. 公司基本面

财务质量：

- 成长性：营收、利润增速，量增还是价增。
- 盈利能力：毛利率、净利率、ROE、ROIC。
- 现金流：经营现金流是否匹配净利润，自由现金流是否为正。
- 安全性：资产负债率、有息负债、流动比率、利息保障倍数。
- 运营效率：应收、存货周转、现金转换周期。
- 警惕：应收激增、存货高企、商誉过大、非经常性损益撑利润、大股东高质押。

管理层与治理：

- 管理层是否诚信、有能力。
- 股权结构、利益是否与小股东一致。
- 资本配置能力：分红、回购、并购、再投资回报。
- 关联交易、财务造假嫌疑：一票否决。

### 5. 估值

- 相对估值：PE、PB、PS、PEG、EV/EBITDA、股息率。
- 历史分位：当前估值在自身历史中的位置。
- 同业比较：比同行贵还是便宜，为什么。
- 绝对估值：DCF、DDM，估算内在价值。
- 安全边际：价格是否明显低于内在价值。
- 行业用不同尺子：
  - 成长股：PEG/PS
  - 周期股：PB + 周期位置
  - 金融股：PB/ROE
  - 消费股：现金流 + 品牌溢价

### 6. 时机与情绪

- 技术面：趋势、均线、成交量、支撑阻力、相对强度。
- 资金面：机构持仓、融资余额、成交量变化。
- 情绪面：换手率、波动率、新闻热度、是否极度乐观或悲观。
- 催化剂：财报、新产品、政策、并购、回购、行业拐点。
- 注意：技术面和情绪面是辅助，不是核心。

### 7. 风险与压力测试

- 业务风险：竞争加剧、需求下滑、客户流失。
- 财务风险：债务危机、现金流断裂。
- 估值风险：戴维斯双杀。
- 政策/监管风险。
- 管理层风险：诚信、战略失误。
- 流动性风险：小盘、成交清淡。
- 黑天鹅。
- 压力测试：最坏情况能亏多少？逻辑是否破坏？

### 8. 组合与操作

- 仓位：集中还是分散？与其他持仓相关性？
- 买入方式：一次性、分批、定投、等回调、等催化。
- 卖出条件：基本面恶化、估值过高、逻辑破坏、发现更好机会。
- 止损/止盈：按体系，不拍脑袋。

## 四、评分表

每项 0-5 分：

5=优秀，4=良好，3=中性，2=偏差，1=差，0=无法判断/数据不足。

加权分计算公式：`得分 / 5 × 权重`。

| 维度 | 权重 | 得分 | 加权分 | 简评 |
| --- | ---: | ---: | ---: | --- |
| 能力圈与资金匹配 | 5 | | | |
| 生意模式 | 15 | | | |
| 行业与竞争格局 | 10 | | | |
| 财务质量 | 15 | | | |
| 管理层与治理 | 10 | | | |
| 估值 | 15 | | | |
| 时机与情绪 | 5 | | | |
| 风险与压力测试 | 10 | | | |
| 组合与操作匹配 | 15 | | | |
| 总分 | 100 | | | |

结论阈值：

- 80-100：适合买入/可分批
- 65-79：谨慎偏多，等价格或催化
- 50-64：观察，不适合现在买
- 低于50：不适合/回避
- 数据严重不足：暂不结论

一票否决项：

- 财务造假或严重诚信问题
- 退市风险
- 无法理解其商业模式
- 高杠杆且现金流断裂
- 大股东严重侵害小股东利益

## 五、输出模板

### 1. 结论速览

一句话：适合买入 / 谨慎分批 / 观察等待 / 不适合买入 / 数据不足。

给出总分和核心原因。若用户信息不足，先列出采用的默认假设。

### 2. 评分表

用上面的评分表输出。

### 3. 分维度分析

按能力圈、生意、行业、财务、治理、估值、时机、风险、组合逐项分析。

每项写：结论 + 关键数据 + 数据日期/来源 + 理由。

### 4. 关键风险

列出 3-5 个最可能让投资失败的风险。

### 5. 买入条件与不买条件

- 什么条件下可以考虑买？
- 什么条件下坚决不买？
- 如果已持有，什么条件卖出？

### 6. 操作建议框架

- 仓位：0 / 观察 / 轻仓 / 标准仓 / 重仓
- 买入方式：一次 / 分批 / 定投 / 等回调 / 等催化
- 跟踪指标：财报、行业数据、政策、竞争格局、估值分位

### 7. 数据缺口

明确哪些数据缺失，可能影响结论。

### 8. 免责声明

以上为分析框架，不构成投资建议。

## 六、原则

- 好公司不等于好股票。
- 好股票不等于现在就能买。
- 不懂不碰。
- 价格是核心变量。
- 风险收益比不合适，就不买。
- 逆向投资不等于接飞刀。
- 事实、估算和观点必须分开表达；涉及最新价格、财报、公告或政策时必须标注日期和来源。
